## 수정 사항

- 본문 최대 읽기 폭을 유지하고 좌측 사이드바·본문·우측 목차 및 헤더의 전체 콘텐츠 그룹을 중앙에 배치.
- 검색어 입력 세대별 결과의 유효성 검증, 이전 추천/결과의 선택 차단, 조합 입력 중 이동 방지, 검색 기록 동기화, Escape 닫기 수정.
- 오래된 문서 이동의 로딩 해제 및 검색 강조 스크롤이 최신 이동에 영향을 주지 않도록 정리.
- 모션 감소 설정 변경 시 재생 및 진행 중인 사이드바 애니메이션을 정리.
- 시각 위계 예제 개선 단계에서 로그인 포커스 링을 중립 포커스 색상으로 보이도록 수정.
- 기술 글 4개에서 줄바꿈 수치 예제, dialog 이름과 초기 포커스, `useMemo`, Query Key 설명을 명확하게 수정. 코드 복사 관련 문구 한국어화.
- 전체 문서의 링크·앵커·이미지·콘솔 및 실제 조작 결과, 레이아웃 지표, 검색 경합, 모션/글꼴, 모바일과 브라우저 호환성 회귀 검증을 보강.

모바일 viewport 에뮬레이션은 실제 모바일 기기 확인이 아니며, 브라우저 자동 테스트의 WebKit 또한 물리 Safari와 같다고 간주하지 않는다.
