# 여백 브랜드 자산

두 개의 마주 보는 ㄱ자 형태는 기록의 경계를, 중앙에 남겨 둔 공간과 작은 형광펜 사각형은 이해를 채우는 여백을 표현합니다. 일반적인 펼친 책과 단순한 이니셜도 검토했지만, 작은 크기에서도 여백 자체가 드러나는 형태를 선택했습니다.

- 심볼: `symbol-light.svg`, `symbol-dark.svg`, `symbol-mono.svg`
- 한글 워드마크: `wordmark-light.svg`, `wordmark-dark.svg`, `wordmark-mono.svg`
- 조합: `lockup-light.svg`, `lockup-dark.svg`, `lockup-mono.svg`
- 파비콘: `public/favicon.svg`

심볼은 16px 이상, 워드마크와 조합은 높이 24px 이상을 권장합니다. 주변 여백은 심볼 너비의 1/8 이상 확보하고 비율을 변경하지 않습니다. 밝은 배경에는 잉크색, 어두운 배경에는 밝은 종이색을 사용합니다. 단색 인쇄에는 mono를 사용합니다. 중앙 사각형을 다른 색으로 변경하거나 외곽선 효과를 추가하지 않습니다.

모든 로고의 도형과 한글 글자 윤곽은 여백을 위해 직접 구성한 SVG이며 외부 폰트나 이미지 의존성이 없습니다. 상표 유사성에 대한 법적 검토는 별도로 수행하지 않았습니다.
