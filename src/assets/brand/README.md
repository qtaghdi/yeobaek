# 여백 브랜드 자산

두 개의 면이 맞물리면서 중앙에 빈 사각형을 남기는 D안입니다. 비어 있는 공간을 심볼의 일부로 사용해 아는 것과 이해하는 것 사이의 여백을 표현합니다. 워드마크는 한글 윤곽을 직접 구성하고 획을 가볍게 조정했습니다.

- 심볼: `symbol-light.svg`, `symbol-dark.svg`, `symbol-mono.svg`
- 워드마크: `wordmark-light.svg`, `wordmark-dark.svg`, `wordmark-mono.svg`
- 조합: `lockup-light.svg`, `lockup-dark.svg`, `lockup-mono.svg`
- 파비콘: `public/favicon.svg`

밝은 배경에는 짙은 잉크색, 어두운 배경에는 밝은 색을 사용합니다. 중앙의 투명한 공간과 비율은 유지합니다. 심볼은 16px 이상, 조합은 높이 24px 이상을 권장합니다. 별도 폰트나 이미지 의존성은 없습니다.
