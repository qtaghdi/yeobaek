기술을 사용하는 것과 왜 그렇게 동작하는지 이해하는 것은 다릅니다. 여백은 그 사이에 놓인 질문들을 기록하고 확인하기 위한 공간입니다.

## 읽는 방법

문제 상황을 먼저 봅니다. 동작 원리를 읽고 필요하면 예제를 조작해 확인합니다. 해결 방법은 언제 적합한지, 무엇을 주의해야 하는지도 함께 확인합니다.

모든 노트에 실험이 필요한 것은 아닙니다. 개념은 글과 코드로, 실제 인터랙션은 실험으로 설명합니다.

## 노트의 범위

웹 접근성, CSS, 브라우저, JavaScript와 TypeScript, React, 상태 관리, UI/UX, 디자인 시스템, 아키텍처와 품질을 다룹니다. 각 문서는 작성자가 설명할 수 있는 범위에서 검토 후 추가합니다.

필요한 예제는 페이지 안에서 바로 조작할 수 있습니다. 글을 읽기 위해 다른 사이트로 이동할 필요는 없습니다.
