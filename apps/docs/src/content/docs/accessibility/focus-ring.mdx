포커스 링이 예쁘지 않다고 CSS에 `outline: none`을 넣어본 적은 없으신가요? 마우스로 클릭할 때는 별 문제가 없어 보입니다. 그런데 마우스를 잠깐 내려놓고 Tab만 눌러보면 이야기가 달라집니다. 현재 위치는 어디일까요?

포커스 링을 제거한 상태에서도 실제 포커스는 이동합니다. 다만 사용자에게는 그 위치가 보이지 않을 뿐입니다. 포커스 자체와 포커스를 보여주는 표시를 구분해야 하는 이유입니다.

## focus와 focus-visible, 뭐가 다를까요?

`:focus`는 현재 포커스된 요소에 적용됩니다. 반면 `:focus-visible`은 그중 브라우저가 포커스를 시각적으로 표시할 필요가 있다고 판단한 상황에 적용됩니다.

그래서 `:focus-visible`을 키보드 전용이라고 생각하면 안 됩니다. 텍스트 입력처럼 마우스로 선택해도 키보드 입력이 필요한 요소에는 표시될 수 있습니다. 표시를 구현할 때 `outline`을 사용하면 보통 요소의 박스 크기를 바꾸지 않고 외곽선을 추가할 수 있습니다.

예를 들어 카드마다 같은 두께의 포커스 링을 주더라도 배경색이 달라지면 대비가 달라질 수 있습니다. 링을 그리는 속성과 그 링에 사용할 색을 별도로 관리하면 테마를 바꿔도 포커스의 의미를 유지하기 쉽습니다. 반대로 선택된 항목에만 적용하는 배경색을 포커스 표시로 사용하면 이미 선택된 항목과 키보드로 탐색 중인 항목을 구분하기 어려울 수 있습니다.

## 링을 없애는 대신 바꿔봅시다

```css
button:focus-visible {
  outline: 3px solid currentColor;
  outline-offset: 4px;
}
```

기본 링의 모양이 마음에 들지 않는다면 위처럼 직접 정의할 수 있습니다. 중요한 건 색이나 굵기를 바꾼 후에도 어두운 배경과 밝은 배경 모두에서 현재 위치를 찾을 수 있어야 한다는 점입니다. 실제로 Tab을 눌러보는 것만으로도 자동 검사에서 놓칠 수 있는 부분을 발견할 수 있습니다.

## 공통 컴포넌트에서 링이 필요한 이유

버튼의 배경이 달라져도 포커스를 찾을 수 있어야 합니다. 그래서 저는 기본 스타일을 지울 때 링을 같이 없애기보다는 공통 토큰으로 대체하는 방향이 낫다고 생각합니다. 마우스 클릭만으로 테스트하면 이 차이가 거의 보이지 않습니다. Tab으로 버튼과 링크를 이동해보면 훨씬 쉽게 이해됩니다.
