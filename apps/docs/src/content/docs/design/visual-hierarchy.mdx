## 문제

같은 정보를 표시하고 기능도 동작하는데 화면이 읽기 어렵다면 색상이나 그림자보다 정보의 우선순위를 먼저 확인해 봅니다.

## 직접 확인하기

개선 단계를 하나씩 바꾸면서 읽기 순서가 어떻게 달라지는지 확인하세요. 동일한 이메일 폼이며 실제 인증을 진행하지 않습니다.

## 관찰

- **Typography:** 제목과 보조 정보에 크기와 굵기 차이를 줍니다.
- **Spacing:** 관련 정보는 가까이 두고 다른 그룹은 분리합니다.
- **Color:** 본문, 보조 정보, 주요 행동의 중요도를 구분합니다.
- **Hierarchy:** 다음 행동이 어디에 있는지 명확하게 만듭니다.

## 개선 기준

먼저 정보를 읽고 행동할 순서를 정한 뒤 스타일을 적용합니다. 여백의 크기나 버튼 모양은 하나의 예시일 뿐이며 모든 서비스에서 같은 값이 정답은 아닙니다.
