## 문제

모달이나 팝오버에 큰 z-index를 설정했는데 다른 요소 아래에 가려질 수 있습니다. 자식의 숫자를 올리는 것으로 해결되지 않는 경우 먼저 부모의 쌓임 맥락을 확인해야 합니다.

## 직접 확인하기

부모 A의 값을 1로 바꾸고 자식 A의 값을 9999로 유지해 보세요. 부모 B는 2입니다. 이어 부모 A를 3으로 바꾸면 어떻게 될까요?

## 동작 원리

쌓임 맥락 안의 자식은 해당 맥락 안에서 비교됩니다. 부모가 별도 맥락을 만들면 외부 요소와의 순서는 부모 단위로 결정됩니다. 이 실험의 부모는 위치 지정 요소이며 정수 z-index, transform, opacity 또는 isolation 조건을 통해 맥락을 형성할 수 있습니다.

## 개선

```css
.overlay-root {
  position: relative;
  z-index: 3;
}
```

무조건 더 큰 값을 주기 전에 해당 요소의 조상부터 확인합니다. 필요하다면 DOM 배치를 조정하거나 공통 오버레이 영역으로 분리합니다. 모든 상황에서 z-index 숫자만 바꿔 해결할 수 있는 것은 아닙니다.
