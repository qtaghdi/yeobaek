긴 파일 이름이 있는 카드에서 오른쪽 버튼이 화면 밖으로 밀리는 상황을 생각해 봅시다. 컨테이너에 flex를 사용하고 텍스트 영역에 `flex: 1`을 줬는데도 줄어들지 않을 수 있습니다.

## 왜 발생할까

Flex item의 기본 최소 크기는 많은 일반적인 상황에서 콘텐츠의 최소 크기를 고려합니다. 줄바꿈할 수 없는 긴 문자열이 있으면 남은 공간보다 크더라도 아이템이 충분히 줄어들지 못합니다.

## 직접 확인하기

카드 폭을 줄이고 `min-width: 0`을 켜거나 꺼 보세요.

## 해결

```css
.row { display: flex; gap: 8px; }
.name { flex: 1; min-width: 0; }
.name p {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

`min-width: 0`은 아이템이 줄어들 수 있게 하고, 말줄임은 넘친 텍스트를 표현하는 별도의 규칙입니다. 모든 텍스트를 숨겨야 한다는 뜻은 아닙니다. 전체 내용을 볼 방법이 필요하다면 줄바꿈이나 상세 보기를 제공합니다.

[MDN: min-width](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/min-width)

## 프로젝트에서 이어진 고민

Select 목록에서 휠을 굴릴 때 바깥 페이지까지 움직이는 문제는 목록과 부모의 스크롤 소유권을 구분해야 하는 사례였다. flex 자식이 최소 콘텐츠 폭보다 작아지지 않는 문제 역시 내부 영역의 제약을 먼저 확인해야 한다.

### 검증 기준

바깥 문서, 패널, 내부 목록 각각의 clientWidth/scrollWidth와 스크롤 가능한 축을 조사한다. 긴 문자열이나 320px 너비에서 확인하고 필요한 자식에만 min-inline-size: 0을 적용한다.
